# 🎥 AI YouTube Video Analyzer

An AI-powered YouTube Video Analyzer built using **Python, Agno Agent, Groq LLM, and YouTube Tools**.

The application analyzes YouTube videos and provides structured insights such as video overview, timeline, important events, and key takeaways.

## 🚀 Features

- 🎬 YouTube video analysis
- 🤖 AI-powered analysis using Agentic AI
- 📝 Video overview and summary
- ⏱️ Timeline of important events
- 🔍 Key points and important moments
- 📚 Content organization
- 💬 Interactive AI-powered responses

## 🛠️ Tech Stack

- Python
- Streamlit
- Agno
- Groq LLM
- YouTube Tools
- python-dotenv
